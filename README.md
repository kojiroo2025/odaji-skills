# 一人社長とAI従業員：実践編のスキルファイル

ニュースレター「一人社長とAI従業員」（合同会社ODAJI）の実践編で、読者の方にお配りしているスキルファイルの置き場所です。スキルファイルは、1つの担当業務について、手順・参照する資料・任せる範囲・確認の方法を書いたファイルです。オフィス開設キット（https://github.com/kojiroo2025/odaji-office-kit ）で作った AIオフィスに入れて、Claude Code と一緒に使います。

## お配りしているスキル

| 号 | スキル | ダウンロード |
|---|---|---|
| 第14号（実践編 第2回） | 提案書・企画書作成スキル（proposal-writing）と、Word を作る・検査するプログラム | https://github.com/kojiroo2025/odaji-skills/releases/tag/ai014 |

## ダウンロードと使い方

1. 上の表のダウンロードのページを開き、「Assets」の下にある ZIP のファイル名をクリックしてダウンロードします。
2. エクスプローラーで「ダウンロード」フォルダを開き、ダウンロードした ZIP を右クリックして、「すべて展開」を選択します。
3. 展開してできたフォルダを開き、中にある `.claude`・`Programs`・`Shared_Assets` の3つのフォルダを、AIオフィスのフォルダ（`CLAUDE.md` があるフォルダ）にコピーします。同じ名前のファイルがあると表示されたら、「ファイルをスキップする」を選択し、Claude Code に「同じ名前のファイルがあります。どうすればよいですか」と聞いてください。
4. 展開したフォルダにある説明書（「はじめにお読みください」）を開き、そのあとの手順に進みます。

## ご注意

- お配りしているスキルは、どの会社でも使えるように汎用的に作っています。使いながら、Claude Code と対話して、自社のやり方に合わせて修正してください。
- 同梱のプログラムは、Word の作成と検査だけを行い、外部と通信しません。
